# 统计排序滤波器

## 项目简介

本项目实现了五种基于排序统计的非线性滤波器：

1. **中值滤波器** (Median Filter)
2. **最大值滤波器** (Max Filter)
3. **最小值滤波器** (Min Filter)
4. **中点滤波器** (Midpoint Filter)
5. **修正阿尔法均值滤波器** (Alpha-Trimmed Mean Filter)

这些滤波器都基于对邻域像素进行排序后提取统计量，属于非线性滤波器，在去除脉冲噪声方面表现优异。

## 功能特点

1. ✅ **5种统计排序滤波器**：覆盖不同去噪场景
2. ✅ **中值滤波最优**：对椒盐噪声效果最好
3. ✅ **最大/最小值滤波**：针对性去除单一类型噪声
4. ✅ **阿尔法均值可调**：通过d参数在均值和中值间连续调整
5. ✅ **完整测试**：33个单元测试，覆盖所有功能
6. ✅ **可视化对比**：直观展示不同滤波器效果

## API 文档

### 1. 中值滤波器 ⭐⭐⭐

#### `median_filter(image, kernel_size=3)`

用邻域像素的中值替代中心像素。**对椒盐噪声效果最好**。

**公式：** `f_hat(x,y) = median{g(s,t)}`

**应用场景：**
- ✅✅ 去除椒盐噪声（最佳选择）
- ✅ 保持边缘
- ✅ 去除孤立噪声点

**优点：**
- 对椒盐噪声效果极好
- 能保持边缘
- 不会产生新的像素值

**缺点：**
- 计算复杂度高（O(n log n)排序）
- 对高斯噪声效果一般

---

### 2. 最大值滤波器

#### `max_filter(image, kernel_size=3)`

用邻域像素的最大值替代中心像素。能去除椒噪声（黑点）。

**公式：** `f_hat(x,y) = max{g(s,t)}`

**应用场景：**
- ✅ 去除椒噪声（黑点）
- ✅ 图像膨胀
- ✅ 寻找局部最亮点

**优点：**
- 能有效去除暗点
- 增强亮区域

**缺点：**
- 会使图像整体变亮
- 会扩大亮区域
- 对盐噪声（白点）会恶化

---

### 3. 最小值滤波器

#### `min_filter(image, kernel_size=3)`

用邻域像素的最小值替代中心像素。能去除盐噪声（白点）。

**公式：** `f_hat(x,y) = min{g(s,t)}`

**应用场景：**
- ✅ 去除盐噪声（白点）
- ✅ 图像腐蚀
- ✅ 寻找局部最暗点

**优点：**
- 能有效去除亮点
- 增强暗区域

**缺点：**
- 会使图像整体变暗
- 会扩大暗区域
- 对椒噪声（黑点）会恶化

---

### 4. 中点滤波器

#### `midpoint_filter(image, kernel_size=3)`

用邻域像素的最大值和最小值的平均值替代中心像素。

**公式：** `f_hat(x,y) = (max{g(s,t)} + min{g(s,t)}) / 2`

**应用场景：**
- ✅ 去除高斯噪声
- ✅ 去除均匀噪声
- ✅ 图像平滑

**优点：**
- 对高斯噪声和均匀噪声效果好
- 计算简单（只需找最大最小值）
- 比均值滤波更好地保持边缘

**缺点：**
- 对椒盐噪声效果差
- 受极值影响大

---

### 5. 修正阿尔法均值滤波器 ⭐

#### `alpha_trimmed_mean_filter(image, kernel_size=3, d=2)`

去掉最高和最低的d/2个值后，对剩余像素求均值。

**公式：** `f_hat(x,y) = (1/(mn-d)) × Σ g_r(s,t)`

**参数：**
- `d`: 去除的像素数量（必须是偶数且 < kernel_size²）
  - `d = 0`: 等同于算术均值
  - `d = kernel_size² - 1`: 等同于中值滤波
  - `d = 2-4`: 轻度修正
  - `d = kernel_size² / 2`: 强修正

**应用场景：**
- ✅ 混合噪声（高斯+椒盐）
- ✅ 需要平衡去噪和保边
- ✅ 多种噪声类型共存

**优点：**
- 结合了均值和中值滤波的优点
- 对多种噪声都有效
- 通过d调节可以在均值和中值间连续调整

**缺点：**
- 计算复杂度高（需要排序）
- 参数d需要根据噪声调整

## 技术原理

### 排序统计基础

对于邻域 S_{xy} 内的n个像素值 {g_1, g_2, ..., g_n}，排序后得到：

```
g_1 ≤ g_2 ≤ ... ≤ g_n
```

各种统计量：
- **最小值**: g_1
- **最大值**: g_n
- **中值**: g_{(n+1)/2}（n为奇数）
- **中点**: (g_1 + g_n) / 2
- **修正均值**: mean(g_{d/2+1}, ..., g_{n-d/2})

### 中值滤波的优越性

中值滤波对脉冲噪声效果好的原因：

1. **对极值不敏感**: 排序后取中间值，极值（0或255）不影响结果
2. **边缘保持**: 在边缘区域，中值通常来自主要区域
3. **不产生新值**: 输出值必定是输入值之一

**示例：**
```
邻域: [120, 0, 125, 130, 255, 122, 128, 135, 124]
排序: [0, 120, 122, 124, 125, 128, 130, 135, 255]
中值: 125  ← 噪声(0, 255)被忽略
```

### 修正阿尔法均值的灵活性

通过调整d值，可以在均值和中值之间连续调整：

```
d = 0           →  算术均值滤波
d = 2           →  去除2个极值的均值
d = kernel²/2   →  去除一半极值
d = kernel² - 1 →  中值滤波
```

## 常见问题

### Q1: 何时使用中值滤波？

A: 中值滤波是去除椒盐噪声的首选：
- ✅ 椒盐噪声、脉冲噪声
- ✅ 需要保持边缘
- ✅ 图像中有孤立噪声点

### Q2: 最大值/最小值滤波何时使用？

A: 
- **最大值滤波**: 只有椒噪声（黑点）
- **最小值滤波**: 只有盐噪声（白点）
- **注意**: 会使图像整体变亮/变暗

### Q3: 修正阿尔法均值的d值如何选择？

A: 根据噪声程度：

| 噪声程度 | kernel=5×5(总25个像素) | 建议d值 |
|---------|----------------------|--------|
| 轻微噪声 | 2-4 | 去除少数极值 |
| 中等噪声 | 4-8 | 去除较多极值 |
| 严重噪声 | 8-12 | 接近中值滤波 |

**经验公式**: `d ≈ 噪声密度 × kernel_size²`

### Q4: 中值滤波vs均值滤波？

A:

| 特性 | 中值滤波 | 均值滤波 |
|-----|---------|---------|
| 椒盐噪声 | ✅✅ | ❌ |
| 高斯噪声 | ⚠️ | ✅✅ |
| 边缘保持 | ✅✅ | ⚠️ |
| 计算速度 | ⚠️ | ✅✅ |

### Q5: 为什么中点滤波对高斯噪声好？

A: 高斯噪声分布对称，最大值和最小值的平均值能很好地估计真实值。但对椒盐噪声，极值是噪声，中点会受污染。

### Q6: 卷积核大小如何选择？

A:
- **3×3**: 标准选择，保持细节
- **5×5**: 中等平滑，常用于中等噪声
- **7×7**: 强平滑，用于严重噪声
- **9×9及以上**: 过度平滑，一般不推荐

## 性能优化

1. **使用OpenCV内置函数**
   - 中值滤波: `cv2.medianBlur()`
   - 最大值: `cv2.dilate()`
   - 最小值: `cv2.erode()`

2. **修正阿尔法均值优化**
   - 使用部分排序算法（如快速选择）
   - 只需找到第k小的元素，不需完全排序

3. **合理选择卷积核**
   - 3×3处理9个像素
   - 5×5处理25个像素
   - 7×7处理49个像素
   - 复杂度与kernel_size²成正比

## 与其他滤波器的比较

### vs 均值滤波器

| 特性 | 统计排序滤波 | 均值滤波器 |
|-----|------------|-----------|
| 类型 | 非线性 | 线性 |
| 椒盐噪声 | ✅✅ | ❌ |
| 高斯噪声 | ⚠️ | ✅✅ |
| 边缘保持 | ✅ (中值) | ⚠️ |
| 计算速度 | ⚠️ | ✅ |

### 选择建议

| 噪声类型 | 首选滤波器 | 次选 |
|---------|-----------|------|
| 椒盐噪声 | 中值滤波 | 修正阿尔法均值 |
| 高斯噪声 | 算术均值 | 中点滤波 |
| 混合噪声 | 修正阿尔法均值 | 先中值后均值 |
| 只有盐噪声 | 最小值滤波 | 中值滤波 |
| 只有椒噪声 | 最大值滤波 | 中值滤波 |
